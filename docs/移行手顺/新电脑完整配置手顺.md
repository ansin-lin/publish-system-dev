# 新电脑完整配置手顺（Publish-System + OpenClaw）

> **适用**：Windows，根目录 `C:\Users\<用户名>\.openclaw`  
> **预计耗时**：首次约 30～60 分钟（含各平台手动登录）  
> **逐项勾选**：[新机检查修改表.md](./新机检查修改表.md)  
> **日常命令**：[manual_commands.md](../参考命令/manual_commands.md)

---

## 0. 部署完成标准

- [ ] `openclaw gateway` 常驻，本机可访问 `http://127.0.0.1:18789`（端口以 `openclaw.json` 为准）
- [ ] `npm run config:check` 通过
- [ ] `npm run orchestrator -- init-db` 成功
- [ ] 各启用平台登录态存在于 `data\auth\<platform>\default\state.json`
- [ ] `create-task` + `run-once` 能推进（Step4 Slack、Step5/6 Gateway、Step7 浏览器）
- [ ] 定时：每天 09:00 JST 建任务 + 每 5 分钟 `run-once`（Cron 或任务计划程序）

## 1. 安装基础软件

按顺序安装并验证：

| 组件 | 要求 | 用途 |
|------|------|------|
| Git | 任意新版 | 拉取 `.openclaw` 整仓 |
| Node.js | **20 LTS+**（建议 22） | 编排、采集、发布 |
| **Google Chrome** | 稳定版 | 登录/发布用 `channel: "chrome"` |
| PowerShell | 5.1+（系统自带） | 脚本、Cron |
| OpenClaw CLI | `npm install -g openclaw` | Gateway、Step5/6 角色 |

```powershell
git --version
node -v
npm -v
openclaw --version
```

Step2 热点采集在 **`node/src/step2-collect/`**（TypeScript），无需 Python 环境。

## 6. 环境变量（密钥）

用 **用户级** `setx` 或启动脚本；**不要**写入 git 里的 JSON。

| 变量 | 用途 |
|------|------|
| `SLACK_BOT_TOKEN` | Step4 发帖/轮询、Step 完成通知、Step7 retry 轮询 |
| `OPENCLAW_SESSIONS_API_BASE_URL` | 如 `http://127.0.0.1:18789` |
| `OPENCLAW_SESSIONS_API_TOKEN` | 与 `openclaw.json` → `gateway.auth.token` 一致 |
| `PUBLISH_ORCH_CLI_CWD` | `...\publish-system\node` 绝对路径 |
| `GOOGLE_API_KEY` 或 `GEMINI_API_KEY` | Step6 AI 配图（无库存图时） |
| `PUBLISH_ORCH_STEP_NOTIFY` | 设为 `0` 可关 Step 完成 Slack 通知 |

可选覆盖：见 `node/src/orchestrator/envOverrides.ts`。

**Cron / 脚本自动注入 Gateway**（推荐）：

```powershell
. C:\Users\<你>\.openclaw\publish-system\scripts\Import-OpenClawGatewayEnv.ps1
```

`setx` 后需**重开终端**再验证：

```powershell
echo $env:SLACK_BOT_TOKEN
echo $env:OPENCLAW_SESSIONS_API_TOKEN
```

## 8. 平台登录（发布前必做）

### 8.1 双击登录（推荐）

目录：`publish-system\scripts\login\`

| 文件 | 平台 |
|------|------|
| `login-facebook.bat` | Facebook |
| `login-x.bat` | X |
| `login-instagram.bat` | Instagram |
| `login-xiaohongshu.bat` | 小红书创作者 |
| `login-tiktok.bat` | TikTok |
| `login-youtube.bat` | YouTube Studio |

流程：双击 → Chrome 手动登录 → 自动写入 `data\auth\<platform>\default\state.json` → 按 Enter 关窗。

要求：**本机已装 Google Chrome**；登录时不要与 Step7 发同一平台。

### 8.2 命令行（等价）

```powershell
cd C:\Users\<你>\.openclaw\publish-system\node
npm run login -- --platform facebook --profile default
# ... 其它平台同上
```

默认等待约 **30 分钟**（`publish.config.json` → `login_timeout_ms`）。

```powershell
cd C:\Users\<你>\.openclaw\publish-system\node

npm run config:check
npm run orchestrator -- create-task --task-id deploy-test-r01 --run-id r01

```

日志：`publish-system\logs\cron-create-*.log`、`cron-dispatch-*.log`。

## 10. 定时任务

### 10.1 当前 OpenClaw Cron（`cron/jobs.json`）

| 任务 | 周期 | 脚本 |
|------|------|------|
| `publish-daily-create-task` | 每天 **09:00** `Asia/Tokyo` | `daily-create-task.ps1` |
| `publish-dispatch-run-once` | 每 **5 分钟** | `dispatch-run-once.ps1` |

新机必改：两条 job 里 PowerShell 脚本的**绝对路径**（用户名目录）。

### 10.2 Gateway 须常驻

Cron 通过 `agentTurn` 让 Agent 执行 `exec`；Gateway 未运行则任务不触发。

> **已知风险**：`agentTurn` 偶发「Cron 显示 ok 但未真正 exec」。更稳做法：用 **Windows 任务计划程序** 直接调度 `.ps1` / `.bat`（绕过 Agent）。

### 10.3 `run-once` 内含

- `ensure_daily`（若 `step1.ensure_daily.enabled`）：补建当日 r01
- `reconcile` + `dispatch-once`
- Step4 pick 轮询、Step7 Slack retry 轮询

### 10.4 可选：Windows 任务计划程序

直接运行：

- `scripts\daily-create-task.bat`（每天 9:00）
- `scripts\dispatch-run-once.bat`（每 5 分钟）

无需改 `jobs.json`，也不依赖 Agent 是否 exec。

## 12. 常见问题

| 现象 | 处理 |
|------|------|
| `Executable doesn't exist ... chromium` | `npm run install:browsers` |
| 登录/发布打不开或异常 | 安装 **Google Chrome** |
| Step4 不发帖/不收 pick | `SLACK_BOT_TOKEN`、Bot 入频道、`chat:write` + `channels:history`；`config:check` |
| Step5/6 失败 | Gateway 是否运行；`OPENCLAW_SESSIONS_API_*` 与 token 一致 |
| Step6 无图 | `GOOGLE_API_KEY` 或 `data\assets\img\<yyyyMMdd>\` 库存图 |
| Step7 `auth_expired` | 双击 `scripts\login\login-<平台>.bat` 重登 |
| Cron 不跑 / 未建任务 | Gateway 常驻；`jobs.json` 路径；或改任务计划程序直跑 ps1 |
| 多场 r02/r03 | 另加 `daily-create-task.ps1 -RunId r02` 计划任务；关 `ensure_daily` |
