## 1. 环境变量（🔴 不要写入 git JSON）

| 变量名 | 用途 | 新机动作 | 与谁一致 | 完成 |
|--------|------|----------|----------|:----:|
| `SLACK_BOT_TOKEN` | Step4 发帖/轮询、Step 完成通知、Step7 retry | 新机 `setx` 或系统环境变量 | Slack App | [ ] |
| `SLACK_APP_TOKEN` | OpenClaw Slack Socket 模式 | 同上 | Slack App | [ ] |
| `GOOGLE_API_KEY` 或 `GEMINI_API_KEY` | Step5/6 Agent、Step6 AI 配图 | 同上 | Google AI Studio | [ ] |
| `OPENCLAW_SESSIONS_API_BASE_URL` | Node 调 Gateway（Step5/6） | 如 `http://127.0.0.1:18789` | `gateway.port` | [ ] |
| `OPENCLAW_SESSIONS_API_TOKEN` | 同上 | **必须与** `openclaw.json` → `gateway.auth.token` **完全相同** | gateway token | [ ] |

## 11. 快速对照：旧机 → 新机

| 类别 | 旧机 `compu` | 新机 |
|------|--------------|------|
| 根目录 | `C:\Users\compu\.openclaw` | `C:\Users\%USER%\.openclaw` |
| Cron ps1 | 路径含 `compu` | 全局替换 `%USER%` |
| `openclaw.json` workspace/agentDir | 同上 | 同上 |
| `PUBLISH_ORCH_CLI_CWD` | `...\compu\...\node` | `...\%USER%\...\node` |
| 密钥 | 环境变量 + gateway token | 新机重新 `setx`，token 成对一致 |
| Slack 频道/用户 | `publish.orchestrator.json` | 同 workspace 可不变 |
| 登录态 | `data/auth` | 拷贝或 `login-*.bat` |
| 编排 DB | 可拷 | **建议** `init-db` 重建 |
